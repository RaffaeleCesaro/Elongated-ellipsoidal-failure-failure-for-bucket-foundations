# Elongated-ellipsoidal-failure-failure-for-bucket-foundations
This repository provides the spreadsheet for the construction of the elliptical failure surface for monopod bucket foundations, using the simplified analytical solution proposed by Cesaro et al. (2026).

Reference:
Cesaro R., Marveggio P., Flessati L., Boccieri G., Conti R., Di Laora R. (2026). Response of monopod suction caisson under monotonic and cyclic loading: FE modelling using SANISAND‑MS. ISSMGE Journal on Geotechnical Engineering Research
