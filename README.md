# Elongated-ellipsoidal-failure-failure-for-bucket-foundations
This repository provides the spreadsheet for the construction of of the elliptical failure surface for monopod bucket foundations, through the simplified analytical solution proposed by Cesaro et al. (2026)
Reference: Cesaro R., Marveggio P., Flessati L., Boccieri G., Conti R., Di Laora R. (2026). Response of monopod suction caisson under mono-tonic and cyclic loading: FE modelling using SANISAND-MS. ISSMGE Journal on 
Geotechnical Engineering Research
